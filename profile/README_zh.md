# Featurehouse.github

[English](README.md) | 简体中文

烤地瓜模组资源及相关文档的 Markdown 项目索引。

## 项目概述

仓库包含根目录索引与 profile 目录中的 Markdown 入口，用于链接项目仓库及文档，没有应用运行时。

## 技术栈与依赖

Markdown 与 GitHub 渲染，无需安装、包依赖或构建工具。

## 文件结构

- `README.md` — 仓库索引
- `profile/README.md` — profile 目录索引

## 快速上手

通过 Markdown 阅读器打开本页或 `profile/README.md`。相关资料见[模组源码归档](https://github.com/Rayawa/sweet_potato-source)与[文档网站](https://github.com/Rayawa/Featurehouse.github.io)。
